# Portfolio Website

A personal portfolio built with **Next.js**, **React Three Fiber**, and **GSAP** — featuring 3D visuals, smooth scroll animations, and interactive elements.

## Tech Stack

- Next.js 14 (React 18)
- React Three Fiber / Drei / Rapier
- GSAP + ScrollTrigger
- Lenis Smooth Scroll
- SCSS Modules

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

> Requires Node 20+

## Build & Deploy

```bash
npm run build
npm start
```

Compatible with Vercel, Netlify, Railway, or any platform that supports Next.js.
